# Axewear

Frontend application containing a login form, Firebase configuration, API service and local JSON dataset.

## Project structure

`src/pages/LoginForm.jsx`, `src/firebase.js`, `src/services/api.js`, `db.json`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Axewear.git
cd Axewear
```

Run `npm ci`, configure your Firebase project and API endpoint as required, and start with `npm run dev`.
